# 0.5.0 — 2026-10-28

## Added

- **`medical-codes-guide` agent skill** at `skill://medical-codes-guide/SKILL.md`, served over MCP through `createApp({ skills })` (listed in `resources/list`, readable through the `skill://{+path}` template) and shipped under `skills/` in the npm package, Docker image, and `.mcpb`. It covers what the server can't answer, search wording, system choice, and where each RXCUI, NDC, and class ID comes from.
- **Agent Plugins root `plugin.json` and `mcp.json`** (mcp-ts-core 0.13.18 template).
- **`docs/building-the-index.md`** holds the index-build steps formerly in the README.

## Changed

- **Server `instructions` say ICD-10-PCS browses only its top-level sections** and that PCS codes are found with `medcode_search_codes`; the sentence previously described axis-based PCS browsing, which `medcode_browse_hierarchy` does not offer below the section level.
- **Enrichment trailer `effectiveQuery` and `nextCursor` render as code spans in `content[]`** (mcp-ts-core 0.13.18), so a copied query or cursor carries no backslash escapes. `structuredContent` is unchanged.
- **The `.mcpb` drops `better-sqlite3`'s node-gyp `build/config.gypi` and `build/Makefile`** (which recorded local build paths) **and the framework's build-only files** (its `changelog/`, `templates/`, `scripts/`, `CLAUDE.md`, …) (mcp-ts-core 0.13.18 bundle cleaner); the 0.4.2 bundle carried both.
- **`.mcpbignore`** excludes `changelog/`, `CLAUDE.md`, `AGENTS.md`, `plugin.json`, `mcp.json`, and the plugin manifest directories; root `skills/` ships.
- **Dockerfile** creates and copies `skills/` into the production stage.
- **README Getting started** rewritten: hosted `claude mcp add`, local `npx`, one config block for other clients.
- **README and `docs/design.md`** no longer describe ICD-10-PCS axis browsing below the section level; the `medcode_map_codes` error list is restructured.
- **Framework** `@cyanheads/mcp-ts-core` 0.13.16 → 0.13.18: framework skills, `scripts/` (`devcheck`, `lint-packaging`, `clean-mcpb`, `check-skills-sync`), the bug-report issue template, and `CLAUDE.md`/`AGENTS.md` re-synced; `add-skill` framework skill added.

## Fixed

- **The HTTP transport no longer retains each request's signal** (mcp-ts-core 0.13.17): under 0.13.16 every HTTP request leaked about 71 KiB until the process ran out of memory.
