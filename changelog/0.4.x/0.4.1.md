# 0.4.1 — 2026-10-08

## Changed

- **Arguments are repaired before validation** (framework 0.13.14): a numeric string for `limit`, a boolean string for `billableOnly` / `includeHierarchy`, a lone string for `medcode_get_code` `codes` (`"E11.9"` → `["E11.9"]`), and `null` at an optional key (`cursor`, `system`) are accepted. An integer sent for a string field such as `code` becomes its digits (0.13.9).
- **Tool error results carry `data.requestId`**, and their text ends `(reason <r> · request <id>)` (0.13.10).
- **Error `data` omits server stack traces** (0.13.7), **request context** (0.13.8), and **`rootCause`** (0.13.13).
- **`ctx.log` notifications reach the client only at or above `MCP_LOG_LEVEL`** (0.13.11).
- **The `-32602` argument rejection is bounded to 10 issue lines** (0.13.14).
- **MCP SDK `^2.2.0`** via the framework (0.13.9 → 2.1.0, 0.13.11 → 2.2.0): a 2026-07-28 POST without `MCP-Protocol-Version` is refused `400`, and a JSON-RPC batch over 100 messages is refused.
- **`server.json`** npm entries no longer pass `run start:*` and use `runtimeHint: "npx"`; the streamable-http entry sets `MCP_TRANSPORT_TYPE` to `http` (template shape from 0.13.11).
- **Dockerfile** installs production dependencies in a `deps` stage pinned to `$BUILDPLATFORM` and cross-installed for the target (0.13.10), prunes musl-only packages (0.13.11), and moves to Bun 1.4.2 (0.13.7).
- **`.env.example` and the README** document `LOG_TOOL_FAILURE_PAYLOADS` (0.13.8) and the OTLP endpoint variables (base endpoint honored 0.13.7, logs endpoint 0.13.8).
- **`.gitignore` and `.dockerignore`** exclude every `.env*` file except the examples; `.mcpbignore` keeps `.cache/`, `logs/`, and `docs/idea.md` out of the bundle; CodeQL runs one job per language.
