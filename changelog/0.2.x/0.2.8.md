# 0.2.8 — 2026-08-25

## Changed

- **Tool inputs are strict.** An argument key none of the six `medcode_*` tools declares is rejected by name — `Invalid arguments for tool medcode_get_code: Unrecognized key: "systems"` — where it was previously dropped and the call ran without it. Each tool's advertised `inputSchema` now carries `additionalProperties: false`, so a client can see the rule before it calls ([mcp-ts-core#232](https://github.com/cyanheads/mcp-ts-core/issues/232)).
- **Every HTTP endpoint serves protocol revision `2026-07-28`** alongside the 2025 revisions, and `/.well-known/mcp.json` reports it as `mcp_version`. A 2025-era client negotiates exactly as before ([mcp-ts-core#305](https://github.com/cyanheads/mcp-ts-core/issues/305)).
- **`MCP_SESSION_MODE` is documented** in `.env.example` and the README environment table. The published Docker image runs `stateless`; the framework's schema default is `auto`, which resolves to `stateful` — so a source run and the container resolved differently with nothing stating it.
- **Docker:** both stages move to Bun `1.4.0`, both production installs drop the framework's optional peer tiers with `--omit=peer`, and the build stage runs on `$BUILDPLATFORM` instead of under qemu on the amd64 leg of a multi-arch build.
- **`tsconfig.json` typechecks `tests/` alongside `src/` under `noEmit`**, with `tsconfig.build.json` carrying `rootDir: "src"` for emit. Tests reach the Bun-only build scripts by their `.ts` specifier, which the emitting config still forbids.
- **`devcheck.config.json` `outdated.allowlist` is empty**, so every dependency is gated again.
- Framework skills under `skills/`, the `lint:mcp` / `lint:packaging` scripts, and `changelog/template.md` re-synced to mcp-ts-core 0.12.3.

## Added

- **`tests/tools/strict-inputs.test.ts`** — the strict-input contract across all six tools, asserted on both `structuredContent.error` and the rendered `content[]` text.
- **`tests/tools/hierarchy-traversal.test.ts`** — the fixture's three-level ICD-10-CM chain (`A01` → `A01.0` → `A01.00`) walked end to end through `medcode_browse_hierarchy` and back up through `medcode_map_codes`. 276 → 302 tests.
- `.github/CONTRIBUTING.md` and `.github/CODE_OF_CONDUCT.md`.

## Fixed

- **`bun run tree` no longer lists directories `.gitignore` excludes** (`data/`, `.sources/`, `.claude/`). A directory-only ignore pattern matches only a path carrying the trailing slash, which the walker was not passing.
- **Vulnerability reports route to `security@caseyjhand.com`** rather than the general contact address.
