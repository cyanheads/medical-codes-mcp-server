# 0.2.9 — 2026-09-19

## Added

- **`teardown()` closes the bundled SQLite handle** on every shutdown path, pairing `setup()`'s open with the new `closeCodeIndexService()`.
- **`sessionMode: 'stateless'` is declared in `src/index.ts`** rather than left to the deployment's `MCP_SESSION_MODE` default — no handler calls `ctx.requestInput`, so nothing degrades under a stateless connection.
- `framework-skills/release-pr-review/SKILL.md` — the review pass between `git-wrapup` and `release-and-publish` in gated release PR mode.
- `.github/workflows/codeql.yml` — the one CI workflow the framework scaffold now copies.

## Changed

- **An argument rejection is JSON-RPC `InvalidParams` (`-32602`)**, not `ValidationError` — the call never reached a `medcode_*` handler. `structuredContent.error` carries `data.reason: "invalid_arguments"` and a `data.recovery.hint` synthesized from the Zod issues; `content[]` closes with a `Recovery: …` line and a `(reason invalid_arguments)` trailer ([mcp-ts-core#416](https://github.com/cyanheads/mcp-ts-core/issues/416), [mcp-ts-core#445](https://github.com/cyanheads/mcp-ts-core/issues/445)).
- **Client bookkeeping keys (`_meta`, `tool_call_description`, `toolCallId`, any underscore-prefixed key) no longer trip the strict-input rejection.** An ordinary undeclared key is still rejected by name — the 0.2.8 strict-input contract is unchanged ([mcp-ts-core#453](https://github.com/cyanheads/mcp-ts-core/issues/453)).
- **A case-varied spelling of a declared parameter is rewritten to the declared key** — `include_hierarchy` resolves to `includeHierarchy` — only when the declared key is absent from the call ([mcp-ts-core#452](https://github.com/cyanheads/mcp-ts-core/issues/452)).
- **Framework skills moved from `skills/` to `framework-skills/`** and resynced to mcp-ts-core 0.13.6, alongside the `lint:mcp` / `lint:packaging` / `devcheck` scripts and `changelog/template.md`.
- **Releases go through a gated release PR**: `git-wrapup` lands the stack on `release/<version>` and opens a PR, `release-pr-review` reviews it, then `release-and-publish` fast-forwards `main`.
- `.claude-plugin/plugin.json` carries `$schema`, full `author` contact, and `keywords`; issue forms assign new issues to `cyanheads` and route security reports to a private advisory.
- README tool reference rewritten for accuracy — documents `alsoInSystems`, each tool's declared error reasons, and cursor/limit pagination for `medcode_search_codes`, `medcode_map_codes`, and `medcode_browse_hierarchy`.

## Fixed

- **A caller that disconnects mid-call classifies as `RequestCancelled` (`-32011`)** rather than an internal error, whatever the handler was doing when the connection dropped ([mcp-ts-core#421](https://github.com/cyanheads/mcp-ts-core/issues/421)).
